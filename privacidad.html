Política de privacidad

Esta política describe el uso de datos por Agente laboral n8n local, aplicación personal administrada por Alejandro Campusano. Contacto: acampusanog@gmail.com.

Datos de Gmail y finalidad

La aplicación solicita gmail.readonly para leer correo y gmail.send para enviar informes al titular. El permiso de lectura permite acceder a Gmail; el flujo está configurado para seleccionar alertas laborales de los últimos siete días procedentes de remitentes definidos.

Procesa identificadores, asunto, fecha, contenido y enlaces de las alertas seleccionadas para detectar oportunidades, evitar análisis repetidos y elaborar resúmenes. El envío está configurado exclusivamente para entregar al titular los informes de ofertas y networking. El flujo no modifica ni elimina mensajes de Gmail.

Historial profesional

El titular incorpora por separado información profesional y un historial privado de conversaciones y contactos de LinkedIn. Se utiliza para identificar relaciones previas, conservar decisiones y evitar repetir contactos o ignorar pausas. No procede de los permisos de Gmail.

Procesamiento con proveedores externos

La API de OpenAI recibe texto seleccionado de alertas, sus metadatos y enlaces para analizarlos. También puede recibir conversaciones seleccionadas y contexto profesional para preparar recomendaciones de networking. El procesamiento no ocurre íntegramente en el computador del titular.

Las conversaciones privadas no se utilizan como consultas de búsqueda web. Las investigaciones web se orientan a información profesional pública. Los borradores requieren revisión y aprobación antes de cualquier envío a un contacto.

Google conserva el correo en Gmail. OpenAI puede conservar entradas y resultados de acuerdo con sus controles de datos de la API y la configuración aplicable. Esta aplicación no promete retención cero por parte de esos proveedores.

Almacenamiento y conservación

Los registros de oportunidades, contactos, conversaciones y decisiones se mantienen en el almacenamiento privado del titular y sus respaldos. Los registros de ejecución de n8n también pueden conservar datos procesados y resultados. Las credenciales de acceso se configuran en la instalación personal; no se publican en estas páginas.

No se ha establecido un plazo automático de eliminación de los registros privados. Se conservan para dar continuidad al seguimiento hasta que el titular decida eliminarlos. Los respaldos deben eliminarse por separado cuando corresponda.

Control, revocación y eliminación

El titular puede detener el flujo y revocar el acceso desde las conexiones con terceros de su cuenta Google. Revocar el permiso impide nuevos accesos autorizados por esa conexión, pero no borra automáticamente los registros ya guardados. Puede eliminarlos en su instalación y respaldos, o solicitar aclaraciones y eliminación mediante el correo de contacto.

Uso limitado

Los datos se utilizan para las funciones personales descritas; no se venden ni se destinan a publicidad. El uso de información recibida de las API de Google y su transferencia a otros servicios se ajustará a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

Estas páginas y cambios futuros

Estas páginas no contienen formularios, analítica, scripts ni cookies añadidas por su responsable. El proveedor de alojamiento puede mantener registros técnicos de acceso, como direcciones IP. Las páginas no contienen el CV, el historial, las credenciales ni los datos de los contactos.

Cualquier cambio en las finalidades o en los datos compartidos se reflejará en esta política y se comunicará al titular antes de aplicarlo, solicitando una nueva autorización cuando corresponda.
